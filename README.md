# CareShift AI Demo

訪問介護事業者向けのシフト統合・自動割当デモです。

## Demo scope

- 事業者別の訪問予定を統合するイメージ
- AIによるヘルパー割当の再計算
- 未配置・重複・移動困難の警告
- 月間シフト表示
- LITALICO連携用データのプレビュー

## Privacy

この公開デモはすべて架空データです。受領した実際のシフト表、利用者名、職員名などの個人情報はリポジトリに含めません。

## Important

LITALICO連携部分は現時点ではUIデモです。実運用ではLITALICO側の正式なインポート／API／連携仕様を確認して実装します。
